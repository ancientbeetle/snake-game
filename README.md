# Snake

This is my attempt to create a snake game. I think it's obvious to say that structure wasn't the priority, a lot of functions are
scattered everywhere, because the goal of this game wasn't structure but to learn C memory management.

Another motive for this project is that this is such a common project to do yet throughout all the years I've coded I've never 
created a game like this. I'm also doing it just for fun.

I don't think I'll lead this anywhere, maybe I'll remove the dialogs one day, depends if I think this game is worth my time.

For this game, I used SDL3 and tinyfiledialogs, both licensed under the zlib license, read the terms in their respective repos.
